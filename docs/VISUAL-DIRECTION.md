# Visual Direction

## Style

- Friendly, clean, modern, accessible, and nature-focused
- Image-forward layouts with clear species photography
- Calm editorial typography with a welcoming tone for all age groups
- Simple cards, restrained colour, and generous readable spacing

## Design references

- Merlin Bird ID
- iNaturalist
- Seek
- AllTrails
- Parks Canada

Prioritize one-handed mobile use, large tap targets, visible focus states, semantic forms, and reduced-motion support. Do not build a dashboard or use visual styling that implies City of Vancouver endorsement.
